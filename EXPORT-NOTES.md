# Exported from Lovable

This archive contains the full source of the Modguard project (TanStack Start + React 19 + Tailwind v4).

## Run it

1. Install dependencies: `bun install` (or `npm install` / `pnpm install`)
2. Start dev server: `bun run dev` (or `npm run dev`)
3. Build: `bun run build`

## Notes

- `.env` contains only the public (publishable) Supabase/Lovable Cloud key — safe to keep, but point
  `SUPABASE_URL` / `SUPABASE_PUBLISHABLE_KEY` at your own backend if you move off the current one.
- `src/routeTree.gen.ts` is auto-generated by the TanStack router plugin; it regenerates on dev/build.
- The AI helper runs through Lovable Cloud / the Lovable AI Gateway. If you move off Lovable hosting,
  provide your own OpenAI-compatible API key in `src/lib/ai/*.server.ts` and `src/lib/moderation.functions.ts`.
- The database lives in Lovable Cloud (see `drizzle/schema.ts` and `supabase/config.toml`). To migrate,
  back up that database and import it into your own Supabase/Postgres instance.
